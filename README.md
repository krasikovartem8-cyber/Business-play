# Своё дело · бизнес-тренажёр для телефона

Мобильная игра-обучалка: выбираете бизнес и растите его от нуля до корпорации своими решениями. Без зависимостей и сборки — обычный HTML + Canvas. PWA: работает офлайн и ставится на домашний экран телефона как приложение.

## Запуск

Нужен только Node.js:

```bash
npm start
```

Откроется **http://localhost:5173**. Чтобы поиграть с телефона в той же Wi‑Fi сети, откройте адрес, который выведет команда (`http://<ip-компьютера>:5173`), затем «Добавить на экран „Домой“». Папку можно выложить на любой статический хостинг (GitHub Pages, Netlify, Vercel) — сборка не нужна: в настройках репозитория включите Pages для ветки `main`, папка `/ (root)`.

## Как играется

Выбираете тип бизнеса (кофейня, хостел, интернет-магазин, барбершоп, IT-студия, доставка, фитнес, пекарня, автосервис, онлайн-школа или свой вариант), даёте ему название и растите его от стартапа до корпорации. Каждый месяц — ситуация с 2–3 вариантами решения; после выбора показываются последствия, урок о реальном бизнес-принципе, месячный отчёт (клиенты, выручка, расходы, прибыль) и совет наставника.

- Показатели: деньги, спрос, репутация, команда, энергия основателя. Уровни: стартап → малый бизнес → компания → сеть → холдинг → корпорация. Расширение — всегда решение игрока, и оно доступно, только когда бизнес к нему готов.
- Встроенный «режиссёр» подбирает ситуации под текущее состояние и прошлые решения (кредит потребует возврата, инвестор — роста, отложенная проблема вернётся). 38 общих ситуаций + по 3 отраслевых на каждый бизнес, кризисы, выгорание, банкротство, продажа компании.
- **Живая улица** над показателями: своё здание растёт этажами с уровнем, окна горят по силе команды, звёзды над вывеской — репутация; дома клиентов, прохожие идут к вам или к конкуренту в зависимости от репутации и бросают монетки в кассу; конкурент и сеть-гигант появляются по сюжету; сотрудники, основатель с «zzz» при выгорании, управляющий, курьеры, филиалы, времена года. Тап по любому объекту — подсказка.
- Дневник уроков, сохранение прогресса в `localStorage`, звук, вибрация, конфетти на новом уровне.
- **Живой ИИ (Claude).** В настройках можно вставить API-ключ Anthropic и включить режим, в котором каждую ситуацию, варианты, последствия и совет придумывает модель `claude-opus-5` под ваш бизнес и историю решений (официальный SDK `@anthropic-ai/sdk` из CDN, структурированный JSON-ответ). Ключ хранится только в браузере и уходит напрямую в Anthropic. Если ИИ недоступен, ход подбирает встроенный режиссёр.


## Файлы

- `index.html` — игра (интерфейс, экономика, режиссёр ситуаций, подключение ИИ).
- `content.js` — типы бизнеса и библиотека ситуаций с уроками.
- `city.js` — живая улица.
- `sw.js`, `manifest.webmanifest`, `icons/` — PWA.
- `scripts/serve.mjs` — локальный сервер, `scripts/make-icons.mjs` — генератор PNG-иконок (`npm run icons`).
